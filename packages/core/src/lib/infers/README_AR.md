# تقرير تحليل نظام الاستدلال (Infers)

يُقدم مجلد الاستدلالات **`packages/core/src/lib/infers`** نظاماً متقدماً وقوياً لاستدلال الأنواع (Type Inference) استناداً إلى مخططات **Zod v4**. هذا النظام يحاكي محركات الـ ORM الحديثة ويوفر حماية كاملة للأنواع (Type Safety).

---

## 1. نظرة عامة
الهدف الأساسي هو تحويل مخطط Zod خام إلى مجموعة متكاملة من الأنواع البرمجية (Types) التي تضمن صحة البيانات أثناء عمليات الاستعلام والترشيح والتعديل.

---

## 2. تحليل المكونات

| الملف | الوظيفة الأساسية |
| :--- | :--- |
| **`index.ts`** | الواجهة الرئيسية التي تجمع كافة الاستدلالات الممكنة. |
| **`entity.ts`** | فصل الكيان الأساسي (Base) عن علاقاته (Populations). |
| **`unique.ts`** | معالجة حقول التعريف (ID) والحقول الفريدة (Unique). |
| **`autogen.ts`** | إدارة الحقول التي يتم توليد قيمها تلقائياً (مثل التاريخ). |
| **`inputs.ts`** | توليد أنواع مدخلات عمليات الإنشاء والتحديث (Create/Update). |
| **`populate.ts`** | تمكين عمليات الكتابة المتداخلة على العلاقات. |
| **`select.ts`** | إدارة حقول الاختيار (`pick`, `omit`, `pluck`, `include`). |
| **`output.ts`** | حساب نوع المخرج النهائي بناءً على خيارات الاختيار المستعملة. |
| **`where.ts`** | محرك تصفية الاستعلامات (Filtering) المتداخل ودعم المسارات (Dot Paths). |
| **`sort.ts`** | نظام الترتيب (Sorting) للحقول الأساسية والمتداخلة. |

---

## 3. أبرز المزايا التقنية

* **Type Safety**: ضمان صحة الأنواع برمجياً لمنع الأخطاء أثناء التطوير.
* **Recursion**: دعم العلاقات والكائنات المتداخلة لعدة مستويات.
* **Zero Runtime Cost**: الأنواع تختفي عند الترجمة ولا تؤثر على أداء وقت التشغيل.
* **Integration**: تكامل تام مع بنية Zod v4.
